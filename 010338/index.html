A note on Nacireman suprasegmental phonology
Rory Turnbull
September 2026
 

This note discusses some recent findings in Nacireman phonology. This language makes suprasegmental use of overtones on each syllable to encode lexical meaning. This typologically unusual feature is integrated into several morphological alternations in the language.
