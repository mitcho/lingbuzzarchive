A Minimal Compositional Metalanguage for Specifying Agent Behaviour
Franck Binard, Vanja Kljajevic
November 2025
 

Prism is a small metalanguage for specifying the behaviour of tool-using agents in a compositional, linguistically transparent way. It consists of a minimal core (numbers, strings, Boolean choice, pairing, etc.) plus domain-specific contexts that introduce tools, sensors, and actions as lexical items. Agent policies are written as structured expressions of this language that can be read as formal semantic representations and executed directly against real tools and APIs. This makes Prism suitable both for analysing agent behaviour in linguistic terms and for future work where policies are evolved or optimised while remaining interpretable.
