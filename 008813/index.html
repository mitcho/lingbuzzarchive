Tutrugbu Partial ATR (Dis)harmony in Search
David Ta-Chun Shen
March 2026
 

Search, identifying the presence of a given configuration, can indirectly check if a string-peripheral segment is of a particular kind: when, say, every high vowel from itself looks for the first vowel to its left, only the string-first high vowel, if there exists one, cannot find a preceding vowel. With this property, an analysis is proposed for the otherwise systematic ATR harmony between prefixes and a stem in Tutrugbu. [The rule ordering was enunciated in the latest version.]
