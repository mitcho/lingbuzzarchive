The effects of implicit causality, topicality, and controller animacy on temporal adjunct control
Alyssa Lowry
January 2026
 

Non-finite temporal adjuncts often only allow control by the matrix subject, but recent research has shown that non-subject control is also possible. Previous research has found that object control is more likely if the object’s referent is strongly topical. Other research predicts that it should also be possible if the object is logophoric. In three reference choice and acceptability rating experiments, this study demonstrates that object control of temporal adjuncts in English is more widely available than previously thought in sentences such as Alyssa noticed Sergio after sitting in a front-row seat. Object control interpretations are more likely with a supporting context, which can consist of topicality or logophoricity of the object, as well as with more generic referential biases like implicit causality. These results indicate that object control of temporal adjuncts is grammatical in English, even if subject control is often preferred. Exploratory analyses indicate that this cannot be due to structural ambiguity in the adjunct’s attachment height and is unlikely to be a grammatical illusion. Instead, the results support theories arguing that non-subject controlled PRO in temporal adjuncts is simply a null pronoun pro whose reference is determined by several competing constraints.
