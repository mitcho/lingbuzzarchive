Condensed Morse Code: An alternative writing system for Morse code designed for learners
Sami Sued
November 2025
 

This report presents a more space-efficient featural writing system for international Morse code called Condensed Morse Code (CMC) that is geared towards ease of reading and writing for humans, intended to be used as a learning tool for beginners. It considers previous efforts, as well as varying aspects of writing systems and neographies for a planned approach to the design process, with the drafting and development of CMC actively shown. The result provides a familiar format for preexisting Morse code users compact in space, comprised of visually distinct glyphs, optimised for quick handwriting, with a standard set of rules that eliminates ambiguity. It has limitations in its ability to be used in other standards for Morse code and languages other than English, though it can be adapted to suit those needs in further iterations.
