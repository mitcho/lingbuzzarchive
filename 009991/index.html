A unified analysis of prosodic inversion and infixation
Peter Jenks, Hannah Sande
January 2026
 

This paper argues that infixation and prosodic inversion are best analyzed using the same formal tool, namely, prosodic subcategorization. We show that second-position clitics that have been analyzed as prosodic inversion can be reanalyzed in Cophonologies by Phase with prosodic subcategorization frames, P, that target prosodic constituents like ω, ϕ, or ι. This is shown to parallel an analysis of infixation, which is formally ident sub-word prosodic constituents such as C, V, or σ. This paper is the first in-depth exploration of the range of data that can be accounted for using the P-specifications in Cophonologies by Phase, including German contrastive coordinators, Serbo-Croatian second-position clitics, and English expletive infixation.
