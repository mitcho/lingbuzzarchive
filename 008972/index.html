Selective Reproduction in NP-Ellipsis
Ock Hwan Kim, Yoshihisa Kitagawa
January 2010
 

This work proposes a novel analysis of the NP-Ellipsis (NPE) in Korean and Japanese in which a computational process of feature copy selectively reconstructs some features of the antecedent NP onto a base-generated skeletal pro-form [E]. We argue: (i) that this analysis can provide natural solutions to various puzzles involving NPE when we let it interact with the 'referential' feature system of NPs we postulate, and (ii) that it overcomes the obstacles some other alternative approaches encounter.
