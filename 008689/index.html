Eliminating pro from Japanese via Neo-Davidsonian Event Semantics
Hideharu Tanaka, Koji Shimamura
December 2024
 

Since Kuroda (1965), it has been widely assumed that the Japanese lexicon includes a small pro, a phonologically empty but syntactically real pronoun. In this paper, however, we argue that postulating pro is not so innocent. The most puzzling aspect of pro is its untouchability, which means that it fails to merge with any kinds of adnominal particles and modifiers, although such combination is totally possible for overt pronouns in Japanese. To derive this disparity, we claim that Japanese pro should be eliminated altogether. Specifically, based on Williams’ (2015) analysis of implicit arguments in English, we propose a pro-free syntax and a free-variable semantics for null nominal anaphora in Japanese and develop such a theory in tandem with Neo-Davidsonian Event Semantics (e.g., Parsons 1990, Landman 2000). This syntactically more minimalist approach is shown to capture the same range of semantic facts as the pro analysis can.
