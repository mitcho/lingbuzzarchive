Semantic experiments on 'remember' as Gettier cases of memory
Emil Rosina
November 2025
 

[updated title: On using experiments on remember as evidence in formal semantics] The German memory predicates noch wissen (‘still know’) and sich erinnern (‘refl remember’) are each used to report two kinds of remembering that are commonly considered clearly distinct in philosophy and cognitive science: experiential remembering of personally experienced events and fact-only remembering of propositions. This methodological paper brings together my existing semantic and experimental work on memory reports involving these predicates. It discusses the questions (i) to which extent experiments on memory predicates can be decisive between formal semantic accounts and (ii) which methodological challenges arise from the multi-disciplinary nature of debates on different kinds of remembering. I argue that to do justice to the usage of memory predicates, individual judgements about other people’s cognition must be given a place in the composition. However, any semantic account fulfilling this requirement becomes harder to falsify and the decision between many possible formal accounts is reduced to a modelling choice.
