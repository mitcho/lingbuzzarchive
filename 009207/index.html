Greek fortition in Logical Phonology
Kyle Gorman
March 2026
 

Markopoulos and Revithiadou (2023), henceforth M&R, describe a process of manner dissimilation in Modern Greek by which certain labial fricatives, those spelled φ, β strengthen (and devoice in the case of β) to [p] before the sibilant /s/; they are realized as [f, v] elsewhere. However, some labial fricatives, spelled υ, never undergo fortition. M&R analyze this pattern using Gradient Harmonic Grammar. I show that it can be generated using the more modest architectural assumptions of Logical Phonology.
