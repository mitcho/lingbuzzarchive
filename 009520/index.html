Restricting Externalization
Aidan Malanoski, Jason Kandybowicz
November 2025
 

It is standardly assumed that linear order is asymmetric and that Vocabulary Insertion is one-to-one. We argue that both assumptions should be abandoned: linear order is antisymmetric, thereby allowing reflexivity, and Vocabulary Insertion is many-to-many. We show that these assumptions allow for straightforward accounts of (i) the linearization of simultaneity, (ii) the generation of multiple exponence, and (iii) the insertion of portmanteaux, all without adopting additional morphological primitives. Ultimately, we advance a research program called Intermodular Morphology, which seeks to account for morphological phenomena using only the syntax, phonology, and intermodular (PF) operations that translate between them.
