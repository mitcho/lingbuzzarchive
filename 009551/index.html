Localizing to-do lists
Yunhui Bai, Jonathan Caleb Kendrick
May 2025
 

According to a prominent pragmatics model, assertions update the context set and imperatives update the to-do lists of the global context. While there has been a long tradition to posit a localized context set (“the local context”), no attempt has been made to localize the to-do list. We suggest that there is a need for local to-do lists, making the local context a pair of local context set and local to-do lists, to explain declaratives-and-imperative conjunctions and disjunctions (e.g, 'Don’t plagiarize or you’d be caught’).
