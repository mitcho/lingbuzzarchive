Gradual weakening across morphological layers: Solving stratal paradoxes in Kashaya
Eva Zimmermann
August 2025
 

Harmonic Layer Theory can correctly predict the interaction of metrical processes in Kashaya which results in an ordering paradox in a classical stratal system. This novel cyclic formalization of the morpho-phonology interface predicts that processes can be restricted to elements that already underwent a previous optimization cycle – while novel elements added in a later cycle are simultaneously present.
