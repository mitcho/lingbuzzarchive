The Nominal Left Periphery in German: Abstract Agreement Chains
Dorian Roehrs
July 2025
 

As is well known, concord holds between different nominal elements of the noun phrase. This paper identifies a restriction on this process. Given certain grammaticality contrasts, this restriction becomes apparent in the DP-layer if an element occurs in the left periphery, that is, above the DP-layer. I propose that an abstract agreement chain is built in syntax that must exclude (possessive) genitive features. It will become clear that the DP-layer plays an important role. First, this restriction only manifests itself in the DP-layer. Second, the DP-layer of definite DPs must contain an overt element – under certain conditions, this layer attracts items like alle ‘all’ and beide ‘both’, which can be merged in different positions. Briefly extending the discussion to other Germanic languages, it appears that only languages with genitive case exhibit this restriction on the agreement chain.
